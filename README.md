# 테트리스 · BLOCK STUDIO

설치 없이 실행하는 한국어 테트리스 게임입니다. 게임 코드, 스타일, 효과음이 `index.html` 한 파일에 포함되어 있습니다. 외부 라이브러리, 서버, API 키가 필요하지 않습니다.

## 먼저 실행하기

압축을 풀고 `index.html`을 Chrome 또는 Edge로 열어 `게임 시작`을 누르세요. 인터넷 연결 없이도 게임을 실행할 수 있습니다. 휴대폰에서는 배포된 웹 주소로 접속하는 방법이 편리합니다.

## 포함 파일

| 파일 | 용도 |
| --- | --- |
| index.html | 게임 전체 소스 및 실행 파일 |
| vercel.json | Vercel 정적 사이트 배포 설정 |
| README.md | 실행, 조작, GitHub 업로드 및 배포 안내 |
| .gitignore | 로컬 도구의 임시 파일 제외 |

## 게임 기능과 규칙

가로 10칸, 세로 20칸 게임판에서 7종류의 블록을 쌓습니다. 한 줄을 빈틈없이 채우면 그 줄이 사라집니다. 새 블록이 나올 자리가 막히거나 블록 일부가 게임판 위에서 고정되면 게임이 끝납니다.

7종류를 한 번씩 섞어 제공하는 방식으로 블록을 배정합니다. 다음 블록 세 개, 블록 보관, 착지 위치 윤곽선, 일시정지, 재시작, 효과음 켜기와 끄기를 제공합니다. 회전할 때 주변의 빈자리를 확인하는 간단한 보정 규칙을 사용하며, 공식 대회용 회전 규격 전체를 구현한 것은 아닙니다.

한 번에 1줄은 100점, 2줄은 300점, 3줄은 500점, 4줄은 800점에 현재 레벨을 곱합니다. 수동 내리기는 한 칸에 1점, 즉시 내리기는 한 칸에 2점을 더합니다. 누적 10줄마다 레벨이 올라가며 블록이 빨라집니다.

최고 점수는 해당 브라우저의 로컬 저장소에 저장됩니다. 기기나 브라우저가 바뀌면 공유되지 않으며, 브라우저 데이터 삭제나 시크릿 모드에서는 기록이 유지되지 않을 수 있습니다. 저장이 차단되어도 게임 자체는 계속 실행됩니다. 다른 창이나 탭으로 이동하면 자동으로 일시정지합니다.

## 조작법

| 동작 | 키 |
| --- | --- |
| 좌우 이동 | 왼쪽, 오른쪽 방향키 |
| 시계 방향 회전 | 위쪽 방향키 또는 X |
| 반대 방향 회전 | Z |
| 한 칸 내리기 | 아래쪽 방향키 |
| 즉시 내리기 | Space |
| 블록 보관 및 교환 | C |
| 일시정지 및 계속하기 | P 또는 Esc |

휴대폰에서는 게임판 아래의 버튼을 사용하세요. 좌우 버튼을 길게 누르면 연속 이동합니다. 블록 보관은 블록 하나를 고정하기 전까지 한 번만 가능합니다.

## GitHub 웹에서 업로드하기

1. GitHub에 로그인하여 새 저장소를 만듭니다. 이름은 예를 들어 `tetris-game`으로 지정합니다.
2. 압축 파일을 먼저 풉니다. ZIP 자체를 올리는 것이 아니라 압축 안의 파일을 올립니다.
3. 저장소의 파일 업로드 화면으로 이동합니다. 이미 파일이 있으면 `Add file`에서 `Upload files`를 선택합니다. 빈 저장소에서는 기존 파일 업로드 링크를 사용할 수 있습니다.
4. `index.html`, `vercel.json`, `README.md`를 올리고 변경 사항을 커밋합니다. `.gitignore`도 함께 올릴 수 있습니다.
5. 저장소 첫 화면에 `index.html`이 보이는지 확인합니다. 폴더 안에 올렸다면 아래 Vercel의 Root Directory 설정에서 그 폴더를 선택해야 합니다.

공식 안내: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

## Vercel에서 배포하기

1. Vercel에 로그인하고 새 프로젝트를 생성합니다.
2. GitHub 연결을 통해 방금 만든 저장소를 가져옵니다. 저장소가 목록에 보이지 않으면 Vercel의 GitHub 접근 권한에 해당 저장소가 포함되어 있는지 확인합니다.
3. Framework Preset은 `Other`를 선택합니다.
4. Root Directory는 `index.html`이 있는 폴더로 지정합니다. 위와 같이 저장소 최상위에 파일을 올렸다면 기본값을 유지합니다.
5. Build Command는 비워 둡니다. 필요한 경우 Override를 켠 뒤 빈 값으로 둡니다. Output Directory는 `.`입니다. 이 프로젝트의 `vercel.json`에도 정적 사이트 설정이 포함되어 있습니다.
6. Deploy를 실행하고 배포 완료 후 제공되는 주소를 엽니다.
7. 게임 시작, 회전, 즉시 내리기와 휴대폰 버튼을 직접 확인한 뒤 주소를 공유합니다.

빌드와 패키지 설치가 필요 없는 HTML 사이트입니다. Node.js 설치나 환경변수 등록은 필요하지 않습니다.

공식 안내: https://vercel.com/docs/builds/configure-a-build

## 명령어로 GitHub에 올리는 경우

이미 Git을 설치했고, GitHub에 비어 있는 저장소를 만들었다면 게임 폴더에서 실행합니다. 아래 `YOUR_ID`와 저장소 이름은 자신의 값으로 바꾸세요. 이 명령어들은 안내용이며, 제공 파일에 GitHub 연결이 이미 설정된 것은 아닙니다.

```bash
git init
git add index.html vercel.json README.md .gitignore
git commit -m "Add browser Tetris game"
git branch -M main
git remote add origin https://github.com/YOUR_ID/tetris-game.git
git push -u origin main
```

## 확인 범위

JavaScript 문법과 게임 로직 11개 시나리오를 모의 DOM 환경에서 확인했습니다. 시작, 블록 배정, 벽 충돌, 회전, 보관 제한, 일시정지, 네 줄 삭제와 점수, 레벨 상승, 즉시 내리기, 게임 종료, 재시작이 포함됩니다. 실제 브라우저의 시각적 배치, 터치 기기, 오디오 출력과 Vercel 배포 환경은 아직 실기 검증하지 않았습니다. 선택적 브라우저 상태 조회 도구는 모의 환경에서만 검증했습니다.
